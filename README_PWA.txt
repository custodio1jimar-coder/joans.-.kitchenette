JOAN'S KITCHENETTE PWA

IMPORTANT:
Upload the CONTENTS of this ZIP to the ROOT of your GitHub Pages repository.
Do NOT upload the JKPWA folder itself.

The repository root must contain:
index.html
manifest.webmanifest
sw.js
logo.jpg
gcash_qr.jpg
icons/icon-192.png
icons/icon-512.png

GitHub Pages:
Settings -> Pages -> Deploy from a branch -> main -> / (root)

Then open your GitHub Pages URL.
Android: Chrome -> Add to Home screen / Install app.
iPhone: Safari -> Share -> Add to Home Screen.
Windows: Edge/Chrome -> Install app.

Barcode:
The ADD/EDIT ITEM screen now has a camera barcode scanner.
Use HTTPS (GitHub Pages) and allow camera permission.
The scanner uses the device camera and can read common EAN/UPC/Code 128 formats.
